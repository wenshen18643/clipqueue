ClipQueue privacy policy

Last updated 26 October 2026.

What it accesses

ClipQueue uploads video files the user selects, with the title, caption, tags and publish time the user sets, to the user's own accounts. It requests only upload permissions:

  • YouTube: Google OAuth scope https://www.googleapis.com/auth/youtube.upload.
  • TikTok: user.info.basic and video.upload (videos go to the user's TikTok inbox as drafts).
  • Instagram: instagram_basic and instagram_content_publish, with the Facebook Page permissions needed to find the linked Instagram account.

What it stores

The sign-in tokens each platform issues are saved in a file on the user's own computer. No data is sent to, or stored on, any server other than the platform's own. ClipQueue does not collect analytics, does not share or sell data, and does not use data from these APIs for any purpose other than uploading the user's own videos.

ClipQueue's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube is subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Deleting the token file removes ClipQueue's access on that computer. Access can also be revoked at any time: Google at myaccount.google.com/permissions, TikTok under Settings → Security → Apps and services, and Instagram/Facebook under Settings → Apps and websites.
