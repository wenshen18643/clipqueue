ClipQueue privacy policy

Last updated 26 October 2026.

What it accesses

ClipQueue uses Google OAuth with the https://www.googleapis.com/auth/youtube.upload scope only. It uses that permission to upload video files the user selects, with the title, description, tags and publish time the user sets, to the signed-in YouTube channel.

What it stores

The sign-in tokens Google issues are saved in a file on the user's own computer. No data is sent to, or stored on, any server other than Google's. ClipQueue does not collect analytics, does not share or sell data, and does not use data from Google APIs for any purpose other than uploading the user's own videos.

ClipQueue's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube is subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Deleting the token file removes ClipQueue's access on that computer. Access can also be revoked at any time at myaccount.google.com/permissions.
